# DigiCode releases

The published macOS disk images for **DigiCode**, a native code editor by
[Digipacket](https://digipacket.net). The source lives in a private repository;
this one exists so the download is open.

## Installing

```sh
brew install --cask digipacket-net/tap/digicode
```

Or take the `.dmg` from [Releases](../../releases) and drag DigiCode to
Applications. Downloaded by hand, it has to be opened the first time with a
right click and then **Open**: DigiCode is signed but not notarised by Apple.

Universal — native on Apple Silicon and on Intel. Requires macOS 13 Ventura or
later.
